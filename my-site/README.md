# Faraz Oman — career timeline

An interactive résumé with a curved career timeline, walking character, and skills field guide.

The site lives in `public/index.html`, with its JavaScript, styles, and SVG assets alongside it. The existing Create React App entry in `src/index.js` is intentionally empty; it keeps the original development and build commands available.

From `my-site`, run `npm install` once, then `npm start` for local development or `npm run build` to create a production build in `build/`.
